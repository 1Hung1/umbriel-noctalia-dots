# umbriel-noctalia-dots
My Umbriel and Noctalia dotfiles

Installation: git clone this repo and copy everything in the root of the git repo

Needed Packages: 
- If on Gentoo: Add the GURU overlay and install: umbriel noctalia xwayland matugen qt6ct alacritty jetbrains-mono
- If on a Arch-based distro: Install: umbriel noctalia xorg-xwayand matugen qt6ct alacritty ttf-jetbrains-mono
- If on NixOS: follow the NixOS setup [guide](nixos-setup.md) or use my nixos config at [1Hung1/nixos-config](https://github.com/1Hung1/nixos-config)
